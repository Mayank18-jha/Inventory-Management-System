# 📦 Inventory Management System

## 📌 Project Overview
The Inventory Management System is a console-based application designed to manage product stock efficiently. It allows users to add products, update stock levels, monitor inventory, and receive low-stock alerts. This system simulates real-world inventory handling used in shops, warehouses, and small businesses.

---

## 🎯 Features
- Add new products with category, price, and quantity
- Update stock levels (IN / OUT)
- View complete inventory list
- Low-stock alert system
- Persistent data storage using SQLite
- Menu-driven console interface

---

## 🛠️ Tech Stack
- **Programming Language:** Python  
- **Database:** SQLite  
- **Libraries Used:** sqlite3, os
